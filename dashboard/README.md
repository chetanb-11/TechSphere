# VoltGadgets E-Commerce Frontend

This is a modern React e-commerce frontend tailored for an electronics store. It was built with Vite, React, TypeScript, Tailwind CSS, and Zustand. 

## Quick Start

```bash
# Install dependencies
npm install

# Run the development server
npm run dev

# Build for production
npm run build
```
